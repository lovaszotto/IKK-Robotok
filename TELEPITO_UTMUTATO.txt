IKK04 DOKUMENTUM WEB-ELLENŐRZŐ RENDSZER - TELEPÍTŐ ÚTMUTATÓ
===========================================================

RENDSZERKÖVETELMÉNYEK:
- Windows 10/11
- Python 3.8 vagy újabb verzió (python.org)
- Microsoft Outlook (email küldéshez)
- Chrome vagy Firefox böngésző (webes ellenőrzéshez)

TELEPÍTÉS LÉPÉSEI:
1. Ellenőrizze, hogy a Python telepítve van:
   - Nyisson terminált (PowerShell)
   - Írja be: python --version
   - Ha nincs Python, telepítse a python.org oldalról

2. Futtassa a telepítőt:
   - Dupla kattintás: telepito.bat
   - Vagy PowerShell-ből: .\telepito.bat

3. Automatikus telepítési könyvtár:
   - SandboxRobots -> InstalledRobots könyvtár cserélésével
   - Példa: C:\MyRobotFramework\InstalledRobots\IKK04-Dokumentum-WEB-Ellenőrzés

4. Várjon a telepítés befejezésére (virtuális környezet létrehozása és csomagok telepítése)

TELEPÍTÉS UTÁN:
1. Menjen a telepítési könyvtárba
2. Szerkessze az IKK.config fájlt:
   - email = az ön email címe
   - input_folder = DOCX fájlok helye
   - output_folder = Excel exportok helye

3. Futtassa: start.bat (dokumentum formálellenőrzés)
4. Vagy futtassa: webserver.bat (webes interfész)

TELEPÍTETT KOMPONENSEK:
- Robot Framework (automatizálás és tesztvezérlés)
- Selenium Library (webes automatizálás)
- Database Library (adatbázis műveletek)
- Requests Library (HTTP kliens)
- OpenPyXL (Excel export)
- Python-docx (DOCX olvasó)
- Flask (webes szerver)
- LXML (XML/HTML feldolgozó)
- Pillow (képfeldolgozó)
- LangDetect (nyelv felismerés)
- Teljes forráskód és erőforrások
- Virtuális környezet (rf_env)

FŐBB FÁJLOK ÉS MAPPÁK:
- start.bat                    - Fő program indítása (dokumentum ellenőrzés)

HASZNÁLAT:

DOKUMENTUM ELLENŐRZÉS MÓD:
1. Helyezze a DOCX fájlokat a konfigurált bemeneti könyvtárba
2. Futtassa: start.bat
3. Ellenőrizze az email-ben érkezett eredményeket
4. Excel fájl: kimeneti könyvtár

WEBES ELLENŐRZÉS MÓD:
1. Futtassa: webserver.bat
2. Nyissa meg böngészőben: http://localhost:5000
3. Vagy nyissa meg: web\robot_runner.html
4. Webes interfészen keresztül indíthat teszteket
5. Eredmények: results\ könyvtár

HIBAELHÁRÍTÁS:
- Log: results\log.html
- Report: results\report.html
- Konfiguráció: IKK.config szerkesztése
- Webes problémák: böngésző konzol ellenőrzése
